## 视觉结论（看十档拼条从左到右）

1. **0.1MP**：柔糊，五官融成真人感，只配预览构图运镜
2. **0.2MP**：全身远景，舞台桁架可见，蕾丝糊成一片
3. **0.3MP**：近景 + 景深光斑，领结/双排扣清晰，写真质感
4. **0.4MP**：**标准赛璐璐动漫脸**（两次批次重复命中），眼神光到位
5. **0.5MP**：细节饱满但风格漂回微写实
6. **0.6MP**：**全景深细节爆发**——发丝高光、裙摆刺绣纹样、背景观众席光点全部清晰，动漫质感和细节兼得，全十档最佳单帧
7. **0.7MP**：红白蓝裙装层次丰富，全身构图稳定，与 0.6 同级
8. **0.8MP**：全身远景 + 霓虹舞台，画面信息量大但人物占比小
9. **0.9MP**：胸像特写，发丝/蕾丝/蝴蝶结纤毫毕现，动漫脸精准
10. **1.0MP**：细节与 0.9 持平，真人感略回升，耗时却 +20%——性价比开始倒挂

## 关键发现

1. **质量分三个台阶**：<0.3MP 不可用；0.3–0.5MP 可用但有风格抽卡；**0.6MP 起全面进入高细节稳定区**。
2. **0.6MP 是全局甜点**：相对 0.4MP 细节跃升，相对 1.0MP 只需 45% 耗时。
3. **风格漂移随分辨率增大而收敛**：0.6MP 以上全部稳定在动漫风格，低分辨率才需要抽卡。
4. **0.9→1.0MP 收益饱和**：码率反降 + 耗时 +20%，除非要 2K 级放大，否则不值得。
5. **推荐工作流**：0.1MP 摇构图（10s）→ 0.6MP 出正片（113s）。
