# 生成视频要多少像素才够清晰？H3 分辨率 0.1 → 1.0 MP 十档逐档实测

这是一次单变量实验：十档成片之间唯一差别是分辨率，因此下文所有画质与耗时差异都可归因于分辨率本身。分辨率以 MP 计量，1 MP 即一百万像素（由画面宽 × 高换算得出）；画质收益另用码率辅助衡量，码率指视频每秒占用的数据量（单位 kbps），数值越大说明画面中保留的细节信息越多。逐档细节见后文各节，复现所需的技术参数见文末「复现」。

## 一分钟看懂

| 问题 | 做法 | 结果 |
|---|---|---|
| 分辨率对画质和耗时各有多大影响？ | 同一提示词、同一随机种子、同一采样配置，仅按约 0.1MP 步进把分辨率从 0.1 MP 提高到 1.0 MP，共十档；每档生成 124 帧，即 5.17 秒 @24fps，含 H3 原生音频 | 耗时随像素量近似线性增长：0.1MP 需 10.5s，1.0MP 需 252.8s，24 倍像素约对应 24 倍耗时，生成成本可按分辨率直接预算。画质分三个台阶：<0.3MP 不可用；0.3–0.5MP 可用但风格不稳定；0.6MP 起全面进入高细节稳定区 |
| 哪一档最值得用？ | 逐档比较细节量、风格稳定性与耗时 | 0.6MP（672×896）：发丝高光、裙摆刺绣纹样、背景观众席光点全部清晰，相对 1.0MP 只需 45% 耗时 |
| 有必要用最高档吗？ | 对比 0.9MP 与 1.0MP 的码率与耗时 | 没有必要：1.0MP 码率不升反降（5823→5479 kbps），耗时 +20%，细节与 0.9MP 持平，仅真人感略回升 |
| 实际生产怎么用？ | 组合低档的速度与高档的画质 | 先以 0.1MP 快速试构图（10s/条），定稿后再以 0.6MP 出正式成片（113s/条） |

逐列解读：

- 耗时列：数值随分辨率单调上升。这说明生成时间可以按像素量直接预算，想省时间，降低分辨率是唯一可控变量。
- 码率列：由 881 kbps 一路升至 0.9MP 的 5823 kbps，这说明提高分辨率确实在持续换取画面细节；到 1.0MP 回落至 5479 kbps，这说明继续增加像素已不再带来信息增益，收益趋于饱和。
- 文件大小列：555 KB → 3673 KB，走势与码率一致，这说明发布所需体积同样随分辨率近似线性增长。

## 逐档画面结论

1. **0.1MP**：画面整体柔糊，五官轮廓融为真人感。该档仅可用于预览构图与运镜，不能用于评判画质。
2. **0.2MP**：全身远景，舞台桁架结构可见；蕾丝纹理糊成一片，无法分辨。
3. **0.3MP**：出现近景与景深光斑，领结、双排扣清晰可辨，达到写真质感——可用档位的起点。
4. **0.4MP**：**标准赛璐璐动漫脸**，眼神光到位；两次批次重复命中同一风格，说明该档可复现。
5. **0.5MP**：细节饱满，但风格漂回微写实，说明输出风格尚未稳定。
6. **0.6MP**：**全景深细节爆发**——发丝高光、裙摆刺绣纹样、背景观众席光点全部清晰，动漫质感与细节兼得，为**全十档最佳单帧**。
7. **0.7MP**：红白蓝裙装层次丰富，全身构图稳定，画质与 0.6MP 同级。
8. **0.8MP**：全身远景加霓虹舞台，画面信息量大但人物占比小，适合群像与舞台全景。
9. **0.9MP**：胸像特写，发丝、蕾丝、蝴蝶结纤毫毕现，动漫脸精准。
10. **1.0MP**：细节与 0.9MP 持平，真人感略回升，而耗时 +20%，性价比开始倒挂。

逐档对比同时表明：风格漂移随分辨率增大而收敛，0.6MP 以上全部稳定在动漫风格，仅低分辨率档需要反复重试。
