# H3 分辨率档位扫描 —— 同提示词 0.1 → 0.5 MP 效果与质量对比（每档 5 秒）

同一提示词、同一 seed（91720260）、同一采样配置（8-step turbo / res_multistep），
仅改变分辨率（0.1 → 0.5 百万像素，步进 ~0.1MP），**每档 124 帧 = 5.17 秒 @24fps**，含 H3 原生音频。

## 快速对比

- 同屏拼条：`comparison_strip_5s.png`（左 → 右 = 0.1 → 0.5MP，取 t=2.5s 同帧）
- 同屏视频：`res_comparison_5s.mp4`（5 档并排播放完整 5 秒）

## 视觉结论（看拼条从左到右）

1. **0.1MP（256×352）**：人物完整、动作可读，但整体柔糊，脸部五官融成"真人感"，服装细节全无。可用作构图/运镜预览。
2. **0.2MP（384×512）**：全身远景，舞台桁架和灯光形状出现，但人物仍偏软，裙摆蕾丝糊成一片。
3. **0.3MP（480×640）**：近景 + 强景深光斑，蝴蝶结/领结/双排扣都清晰，观感接近随手拍写真的质感。
4. **0.4MP（544×736）**：**画风突变，标准赛璐璐动漫脸**，眼神光、红黑裙装纹样、白发手套全到位——五档中最"初音"的一版。
5. **0.5MP（608×832）**：细节最饱满（舞台地板反射、观众席、红白蓝三色裙装层次），但风格又漂回微写实。

## 关键发现

- **5 秒时长显著提升稳定性**：0.92s 短片段在低分辨率下五官崩坏，5s 片段即使 0.1MP 人物结构也完整——时序一致性帮助了空间质量。
- **风格漂移依旧**：分辨率改变 latent 布局等于重摇 seed。0.4MP 再次命中标准动漫风（与 0.92s 批次一致），说明该档位倾向动漫先验。
- **质量/成本拐点在 0.4MP**：0.4→0.5MP 耗时 +37%，码率反而下降（3056→2952 kbps），信息增益已接近饱和。
- **低成本工作流建议**：0.1MP（10.5s/条）摇构图 → 0.4MP（62s/条）出正片，性价比最高。
