# 初音舞台六镜双线精剪 —— 接点矩阵穷举重排 + AI 慢放分段修复（赛璐璐 / 真人 cos 两条成片）

> 成片：[recut_cel.mp4](recut_cel.mp4)（25.92s / 672×896 / 含原生音频） · [recut_real.mp4](recut_real.mp4)（22.22s / 672×896 / 含原生音频）
> 在线播放：https://mafeis.github.io/ai-test-lab/#miku-stage-recut

同一支六幕舞台剧情（热舞 → 跳跃 → 转身贴脸 → 伸手合拢 → 鞠躬退场 → 曲终睁眼），用两种画风各生成一遍，各剪一条**纯画风**成片。本实验记录拆线之后的两轮迭代：**A 顺序重排**（镜头怎么排衔接最好，穷举全部排列）与 **B 反慢放**（生成端把"滞空""定格"渲染成了肉眼可见的慢动作，剪辑端分段修复）。两轮各有一组"测试过程 → 数值验收 → 结论对比"，全部数据可由 [scripts/](scripts) 复现。

## 轮次 A：顺序重排——6 镜 720 种排列全部算一遍

方法（[scripts/recut_seq.mjs](scripts/recut_seq.mjs) + [scripts/recut_order.mjs](scripts/recut_order.mjs)）：

1. 每镜解码 12fps / 40×52 灰度，全片邻帧差中位数记为运动基线 BASE；
2. 对全部有序镜对做「A 尾 2.5s × B 首 2.5s」穷举，取最小差作为该接点的姿态匹配值（30 个有序对全留档：[pairs_cel.json](pairs_cel.json) / [pairs_real5.json](pairs_real5.json) / [pairs_real6.json](pairs_real6.json)）；
3. **感知成本**：接点差 ≤1.6×BASE 的部分按硬切全额计入；超出部分由叠化摊薄，只按残差 25% 计入；
4. 全排列穷举求和排序。

| 线 | 选定顺序 | 成本/排名 | 对照 |
|----|----------|-----------|------|
| 赛璐璐（6 镜 720 排列） | 2→3→4→5→6→1 | **24.9 · 1/720** | 原序 1→2→…：34.6（第 2 名，重排收益全部来自最后一刀） |
| 真人（主序 5 镜 120 排列） | 2→3→4→5→6 | **72.2 · 1/120** | 次优 72.5——主序就是数值最优 |
| 真人（含开场镜 6 镜 720 排列） | 开场→2→3→4→5→6 | 101.8 · 7/720 | 数值最优 96.4 把聚光开场镜排进片中部，叙事不合法，弃 |

赛璐璐线的全部收益在一刀：`退场6→睁眼1 = 31.2`（30 个有序对里第 5 便宜），而睁眼镜放开头 `1→任意 = 55.1~82.1`。**"落灯后接曲终睁眼"天然近乎无缝，"睁眼开场"则要付全矩阵最贵的头刀**——顺序的价值完全可量化。真人次优只差 0.3，说明其成本被三处大幅运镜溶解刀（45~54）压死，排序腾挪空间小，这时穷举的作用是**确认现序已最优**而不是换序。

下刀方案：接点姿态匹配帧做硬切；旋转/跨音床处 0.25~0.35s 叠化防混叠；谢幕进睁眼 0.5s 长叠化。

## 轮次 B：反慢放——先判死"这是缺陷"，再动手

成片中段观感拖沓。四步证据链定性（每一步都可复查）：

1. `ffprobe` 确认源与成片均 24fps CFR——排除时间戳/可变帧率假象；
2. 逐秒能量曲线（[energy_curves.json](energy_curves.json)）：真人线第 8~10 秒跌到 3.2~6.4，前后秒都是 13~24——**能量谷的位置正好落在跳跃镜滞空段**；
3. 提示词原文有 `hangs at the peak of her jump`——生成端把"滞空"当卖点渲染成了慢动作；
4. 物理判据：[slowmo_hang_24fps.jpg](slowmo_hang_24fps.jpg) 24fps 连拍实测离地 0.5s / 落地 3.5s，**滞空 3.0s**；真实跳跃滞空 ≤0.6~0.7s。超出物理 4 倍 = 慢放缺陷，不是风格。

同一手法还造成第二种症状：贴脸/伸手镜尾部 2~3.5s 的近静止"定格漂移"（6fps 抽帧带 [strip_cel_jump_src.jpg](strip_cel_jump_src.jpg) / [strip_real_reach_src.jpg](strip_real_reach_src.jpg)）。

**修复方法**（[scripts/recut_build.mjs](scripts/recut_build.mjs)）：对镜头按源时间分段 `setpts`/`atempo`，坡道 `1×→1.5×→2.7×→1.5×→1×`。三条纪律：

- **变速窗口只落在无运动参照的素材上**（滞空、定格漂移）——画面里没有可对照的位移基准，观众读作风感与紧凑，读不出变速；起跳、落地、转头等真动作一律 1×；
- **已验证的接点几何不动**：所有姿态匹配帧、溶解重叠区都留在 1× 段内，轮次 A 的验收结论继续有效；
- **刻意慢放不清除**：鞠躬退场、曲终睁眼、聚光亮相开场是叙事节奏，保留原速——区分"风格"与"缺陷"的依据同样是物理参照。

参数示例（真人线跳跃镜，源时间轴）：`0~0.5s@1×`（助跑起跳）、`0.5~0.8@1.5×`、`0.8~3.2@2.7×`（滞空）、`3.2~3.6@1.5×`、`3.6~end@1×/1.35×`（落地欢呼尾微收）。

## 测试方式（度量口径）

成片用 24fps（=源帧率，12fps 会把快速运镜折叠漏检）解码 40×52 灰度；邻帧差**中位数**为全片基线（避开首尾淡变）；每刀取 ±0.45s 窗口最大差 / 基线，**≤1.6× 接近无缝、≤3× 溶解可接受**；硬接刀额外看切点两侧边界帧差（窗口 max 会被镜内高运动帧污染，边界帧差才反映真实跳变）；数值之外再看每刀前后帧横排图目检（[verify_cel_joins.jpg](verify_cel_joins.jpg) / [verify_real_joins.jpg](verify_real_joins.jpg)）与整片 1fps 连拍（[_cel_overview](verify_cel_overview.jpg) / [_real_overview](verify_real_overview.jpg)）。

## 验收与结论对比（v4 重排版 → v5 提速版）

| 项 | 赛璐璐 v4 | 赛璐璐 v5 | 真人 v4 | 真人 v5 |
|----|-----------|-----------|---------|---------|
| 片长 | 28.96s | 25.92s（理论 25.85） | 26.38s | 22.22s（理论 22.14） |
| 邻帧差基线 | 3.01 | 3.50 | 6.34 | **9.36**（整体变紧凑） |
| 滞空段能量谷 | 2.4~2.9 连 3 秒 | 0.8~3.0 仅 1 格即回升 | 3.2~6.4 连 3 秒 | 8.9~9.0（谷消失） |
| 定格漂移段 | 1.0~1.4 平台 | 2.2~2.3（1.5× 收紧） | 5.4~6.3 五秒平台 | 8.3~9.6 |
| 跳跃镜观感 | 滞空 2.75s | **~1.2s** | 滞空 3.0s | **~1.3s**（提速后 6fps 连拍：[fixed_cel_jump](fixed_cel_jump.jpg) / [fixed_real_jump](fixed_real_jump.jpg)） |

v5 逐刀（24fps）：赛璐璐 5 刀 = 溶解 16.04(4.58×，旋转镜自身) / 硬 6.31=1.80× / 硬 3.79=1.08× / 硬 10.50(窗口 max 为片内运动，边界帧差 0.31/0.02) / 谢幕长叠 3.50=1.00×；真人 5 刀 = 三处溶解 2.84×/2.53×/2.19×（舞蹈运镜主导）/ 硬 9.42=1.01×（边界 4.61/0.47）/ 硬 14.40=1.54×。真人末刀边界数值 12.16 复核为抽帧索引舍入漂移——[verify_real_joins.jpg](verify_real_joins.jpg) 横排图确认切点两侧画面连续。

**结论对比**：轮次 A 的可量化收益集中在赛璐璐线（成本 -28%，排名 1/720），真人线的收益是"确认无需重排"；轮次 B 把两条线中段合计约 6s 的慢放区压掉（片长 -10.5% / -15.8%），能量曲线谷值全部抬回基线以上，且因为接点帧全在 1× 区，轮次 A 的接点验收**零回退**。提速后基线从 6.34 升到 9.36 属预期现象——阈值都是相对量，验收口径不受影响。

## 发现

- **AI 慢放是生成端属性，剪辑端可修但先量后动**：滞空时间 vs 生理极限是一票判据，能量曲线定位问题秒级，两者都齐了才下变速刀；
- **提速窗口必须无运动参照**：滞空与定格漂移段没有位移基准，2.7× 也读不出来；真动作哪怕 1.2× 都会露馅；
- **穷举给下限与排名，不给最终答案**：真人线数值最优把开场镜排进片中部——数值与叙事冲突时，取"叙事合法集合内的最低成本"（101.8，比数值最优贵 5.6%）；
- **分段变速不破坏既有接点验证**的前提是接点帧全部留在 1× 段，这要在设计坡道时当作硬约束，而不是事后补救；
- **成片验收解码帧率 ≥ 源帧率**：赛璐璐 j1 旋转刀在 12fps 下看不出混叠，24fps 下 4.58× 无所遁形，最终用 0.25s 溶解压制；
- 提示词里的 `hangs at the peak` 是这类缺陷的源头证据——**素材档案（prompts）在后期诊断里和像素一样值钱**。

## 复现

```bash
export FFMPEG=ffmpeg FFPROBE=ffprobe   # 不在 PATH 时改成绝对路径
# 素材置于 <workspace>/videos/<镜名>_00001_.mp4，脚本在 <workspace>/cut/ 同级运行
E=experiments/miku-stage-recut
node $E/scripts/recut_seq.mjs    cel  story2_shot2,story2_shot3,story2_shot4,story2_shot5,story2_shot6,story_shot1
node $E/scripts/recut_order.mjs  cut/mseq/cel/pairs.json story2_shot2,...,story_shot1   # 720 排列排名
node $E/scripts/recut_build.mjs  cel        # 或 real：分段提速 + 叠化 + 淡变，一次编码
node $E/scripts/recut_verify.mjs cel        # 24fps 逐刀验收 + 目检图
```

纯 CPU，全流程几分钟，不需要 GPU。
