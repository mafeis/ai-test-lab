# SeedVR2 精剪成片整条 3x 高清化——定稿流程的首次全片交付

> 最终成片：[recut_final_2016.mp4](recut_final_2016.mp4)（2016×2688 · 22.2s · 含音轨）
> 在线播放：https://mafeis.github.io/ai-test-lab/#seedvr2-recut-3x
> 前置实验：[SeedVR2 放大倍数标定](../seedvr2-upscale/README.md)（3 倍直达改脸 / 1.5 倍保真的红线来源）

## 一分钟看懂

上一轮标定出了定稿流程（SeedVR2 只做 1.5 倍恢复、剩余尺寸本地 lanczos 补齐），但证据停留在 5 秒短片上。这次把它用到 **22.2 秒 / 532 帧的六镜精剪成片**上整条跑完：服务器 426.6 秒 + 本地放大，约 7 分钟产出 2016×2688 成片，表情逐帧零失真。

同素材加测了 3 倍直达探针（48 帧抽样）：13.3 秒/帧，全片需约 2 小时，清晰度只比定稿流程略锐一点。**结论不变且更硬：定稿流程是交付默认，3 倍直达不排。**

| 方案 | 输出尺寸 | 表情 | 耗时 | 结论 |
|------|----------|------|------|------|
| 1.5 倍 + 本地放大补齐 | 2016×2688 | 零失真 | 426.6s + 本地 | ★ 最终流程 |
| 1.5 倍直出 | 1008×1344 | 零失真 | 426.6s | 中间产物 |
| 3 倍直达（48 帧探针） | 2016×2688 | 零失真（本素材） | 639.3s（≈13.3s/帧） | 全片约 2 小时，不排 |

## 本轮新证据

**1. 流程在交付长度上复现成功。** 22.2s 素材全片 426.6s ≈ 素材秒数 ×19，落在标定轮「×15~25」排期口诀区间内。逐帧核对无表情改动、无闪烁、无块界——532 帧整条质量稳定。

**2. 「放大改脸」是概率性风险，不是必然。** 标定轮的真人素材 3 倍直达翻车（抿嘴笑 → 咧嘴露齿）；本条真人素材 3 倍直达探针全程干净（[compare_face_3way.png](compare_face_3way.png) 三方表情一致）。同模型同倍数，一条翻车一条安全——所以红线按素材类别定 1.5 倍，不因单次安全而放松。

**3. 3 倍直达的真实代价是算力。** 13.3s/帧 对定稿流程 0.8s/帧，16 倍算力换半分锐度。分辨率越高时间块切得越碎，这个比值只会更差。

## 环境与参数（复现用）

- 与标定轮完全一致：ComfyUI 0.35.0 核心版 · SeedVR2 7B fp8 官方权重 · 1 step · cfg 1.0 · 色彩校正 lab
- 提交脚本 `run-seedvr.mjs`（随 [seedvr2-upscale](../seedvr2-upscale/README.md) 留档）：`node run-seedvr.mjs --clip <源片> --target 1008x1344 --name <名> --go`
- 本地补齐：`ffmpeg -i 15x.mp4 -vf scale=2016:2688:flags=lanczos -c:v libx264 -crf 16 -preset slow -c:a copy`
- 评测：同帧位整幅与脸部裁剪三方并排，逐帧核对表情；耗时按墙钟计
