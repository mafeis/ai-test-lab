# 补充实验：链式续拍一致性 + 音频提示词隔离（H3 图生视频）

承接 [t2i-ref-i2v](../t2i-ref-i2v/)，回答两个遗留问题。同 0.6MP（672×896）、124 帧 5.17s @24fps、含原生音频、seed 91720260。

## 实验 C：链式续拍——末帧接力能否保住角色

方法：shot1 末帧 → 作为 shot2 首帧 → shot2 末帧 → shot3 首帧，同提示词同 seed，共 3 镜头（shot1 沿用上游实验成片）。

| 镜头 | 首帧来源 | 耗时 | 成片 |
|---|---|---|---|
| shot1 | Z-Image 甜点参考图 | 125.7s | [上游 t2iref_zimg_mp0.6](../t2i-ref-i2v/t2iref_zimg_mp0.6_00001_.mp4) |
| shot2 | shot1 末帧（[shot1_last.png](shot1_last.png)） | 124s | [cont_shot2_00001_.mp4](cont_shot2_00001_.mp4) |
| shot3 | shot2 末帧 | 124s | [cont_shot3_00001_.mp4](cont_shot3_00001_.mp4) |

**结论**
1. **角色一致性链式保持成立**：三镜头的双马尾、水手服、金色双排扣、耳机、脸型全程稳定，无换脸无换装
2. **镜头语言自然衔接**：shot2 从近景拉回全身，shot3 再推近景——末帧接力天然形成"下一镜"的运镜逻辑
3. **轻微漂移存在**：3 镜后脸型比 shot1 略幼、略"甜"，建议链条 ≤3-4 镜，或每 2 镜用参考图校正一次
4. 首帧复用上一镜末帧 = 无缝转场；若想要硬切，应改用同一参考图 + 不同 seed

## 实验 D：音频提示词隔离——改音频会不会带坏画面

变量控制：**完全相同的首帧（Z-Image 甜点图）、相同 seed、相同视觉提示词**，只改音频句：

| 音频提示 | 音轨实测 | 画面 | 成片 |
|---|---|---|---|
| J-pop 电子synth | 独立音轨 A | 构图同基准 | [aud_pop](aud_pop_00001_.mp4) |
| 重摇滚吉他+鼓+欢呼 | 独立音轨 B | 构图同 | [aud_rock](aud_rock_00001_.mp4) |
| 电影管弦（弦乐+钢琴） | 独立音轨 C | 构图同 | [aud_orchestral](aud_orchestral_00001_.mp4) |
| （不写音频句） | 独立音轨 D | 构图同 | [aud_none](aud_none_00001_.mp4) |

**结论**
1. **4 条音轨互不相同**（PCM 哈希各异）——音频提示词确实控制 H3 原生音频的曲风
2. **画面稳定性极好**：同 seed 下 4 条视频的人物、舞台、运镜完全一致，音频提示词没有把画面带偏
3. **"none"不是无声**：不写音频句 H3 仍会自动配乐（mean -14dB）——想要安静场景必须显式写"ambient silence/quiet room tone"之类的提示
4. 实用推论：**音频句可以放心当成独立旋钮调**，不需要为改 BGM 重抽画面
